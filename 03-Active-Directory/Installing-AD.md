1. Open Server Manager
Server Manager opens automatically on login.
If not, launch it from the Start menu.

2. Add Roles and Features
Click Manage

Select Add Roles and Features

Choose Role-based or feature-based installation

Select DC01 as the target server

3. Select AD DS
Tick Active Directory Domain Services

Accept the additional required features

Click Next through the wizard

Click Install

This installs the AD DS role but does not make the server a Domain Controller yet.
